sapscaleR is an R package for up-scaling sap flux density measurements to estimates of whole-tree sap flow rates. It can implement the classic circular model for sap flow estimation ([Caylor & Dragoni 2009](https://doi.org/10.1016/j.agrformet.2008.10.006)) as well as the novel sap flow models presented by [Burnett et al. (2026)](https://doi.org/10.1016/j.agrformet.2026.111357) for irregular and non-convex trunk cross sections.

sapscaleR can be downloaded from the [sapscaleR GitHub repository](https://github.com/m1burnett/sapscaleR). See the [sapscaleR examples vignette](https://github.com/m1burnett/sapscaleR/blob/main/vignettes/sapscaleR-examples.Rmd) for use case examples that can be run in R. If you use sapscaleR in published research, please cite [Burnett et al. (2026)](https://doi.org/10.1016/j.agrformet.2026.111357).
